## 📌 نبذة عن المنصة (Overview)

**VendorProof** هي منصة سحابية مؤسسية ذكية (B2B SaaS Multi-Tenant Platform) صُممت لتمكين المنشآت والشركات من أتمتة عمليات التدقيق، حوكمة وتأهيل الموردين، والتحقق المستمر من التراخيص والشهادات النظامية والمهنية.

تهدف المنصة إلى القضاء على المخاطر التشغيلية والقانونية في سلاسل الإمداد، وتوفير تجربة سلسة تتيح للمؤسسات متابعة مستويات الامتثال لكل مورد لحظياً، والتأكد من مطابقة جميع الشركاء للمعايير والسياسات المعتمدة قبل التعاقد والتعامل المالي.

---

## ✨ أبرز قدرات وميزات المنصة (Key Capabilities)

### ⚡ أتمتة تأهيل وتصنيف الموردين (Automated Supplier Onboarding)
- تنظيم وتصنيف الموردين بحسب قطاعاتهم ونشاطاتهم التجارية (مثل: المقاولات، الخدمات التقنية، التوريد الطبي، الاستشارات).
- فرض سياسات واشتراطات امتثال مخصصة لكل قطاع وتطبيقها فوراً دون جهد يدوي.
- توليد متطلبات وشروط الامتثال تلقائياً لكل مورد جديد بمجرد إضافته للنظام (**Auto-Provisioning Engine**).

### 📊 مؤشر ونسبة الامتثال اللحظية (Live Compliance & Risk Scoring)
- حساب فوري وديناميكي لنسبة امتثال كل مورد بناءً على المتطلبات المستوفاة والمتبقية والمنتهية.
- لوحات مؤشرات بيانية واضحة تبرز الموردين المطابقين، والموردين المعرضين لانتهاء الوثائق، والموردين ذوي المخاطر العالية.

### 📑 حوكمة الوثائق والشهادات النظامية (Document & Certificate Governance)
- كتالوج شامل للشهادات والوثائق والتراخيص الرسمية (مثل: السجلات التجارية، شهادات الزكاة، تراخيص العمل، شهادات الجودة والآيزو).
- تتبع دقيق لتواريخ الصلاحية وتنبيهات استباقية قبل انتهاء الوثائق لضمان استمرارية الأعمال دون انقطاع.
- سجل تدقيق تاريخي وأرشيف رقمي يوثق عمليات الرفع والمطابقة والتجديد.

### 🛡️ محرك سياسات الامتثال والاستثناءات المسببة (Policy Engine & Waivers)
- مرونة تامة في تحديد الوثائق الإلزامية والاختيارية لكل فئة أو مورد.
- إمكانية منح إعفاءات أو استثناءات إدارية مشروطة لمورد معين مع توثيق سبب وتاريخ الاستثناء إدارياً لضمان الشفافية وقابلية التدقيق.

### 🏢 عزل كامل لبيانات الشركات (Enterprise Multi-Tenancy)
- عزل رقمي صارم للبيانات يضمن أن كل شركة مشتركة تمتلك بيئة بيانات مستقلة تماماً ومحمية من أي تداخل أو تسريب.
- إمكانية تخصيص السياسات والمتطلبات لكل شركة بشكل مستقل يناسب طبيعة لوائحها الداخلية.

### 💳 إدارة الاشتراكات وباقات الخدمة (Subscription & Billing Engine)
- دعم باقات اشتراك متعددة المستويات (باقات مجانية، وباقات متقدمة للمؤسسات).
- حوكمة وتحديد سعات الاستخدام (مثل: عدد الموردين، المتطلبات المتاحة، وسعات التخزين) لكل باقة.
- تكامل سلس مع بوابات الدفع الإلكتروني (Stripe) لإدارة الفواتير والترقيات التلقائية.

## 🏛️ المعمارية العامة للمنظومة (Architecture Overview)

تعتمد المنصة على معمارية هجينة ومفصولة (Decoupled & Headless Architecture) تفصل بين مستويين تشغيليين رئيسيين:

```text
┌─────────────────────────────────────────────────────────────┐
│                 VendorProof Cloud Platform                  │
├──────────────────────────────┬──────────────────────────────┤
│    لوحة التحكم والإدارة      │      محرك الأداة السحابي     │
│       (Control Plane)        │        (Core Tool API)       │
├──────────────────────────────┼──────────────────────────────┤
│ • إدارة مالك المنصة والسوبر  │ • واجهات RESTful API عالية   │
│ • حوكمة المنشآت والاشتراكات  │ • تغذية الفرونت إند المفصول  │
│ • إدارة الباقات والأسعار     │ • إدارة الموردين والامتثال    │
│ • جلسات ويب قياسية مؤمنة     │ • مصادقة مشفرة (Sanctum)     │
│ • واجهة Fluid 100% وثيم ليلي │ • عزل تلقائي لبيانات العملاء │
└──────────────────────────────┴──────────────────────────────┘
```

1. **لوحة الإدارة والتحكم (Control Plane)**: بيئة الويب الإدارية المخصصة لإدارة المنصة السحابية، متابعة اشتراكات المنشآت، إدارة الخطط والأسعار، ومراقبة مؤشرات النمو والأداء عبر واجهة مستخدم فاخرة تدعم الوضعين الفاتح والليلي عالي التباين.
2. **محرك الأداة وواجهات الـ Headless API**: واجهات برمجية خفيفة وقوية وسريعة الاستجابة، مصممة لتغذية الواجهات الأمامية المنفصلة (Decoupled Frontends) وتطبيقات الجوال ومواقع الموردين الذاتية بكل مرونة.

## 🔌 واجهات الـ API والتوثيق التفاعلي (API & Integrations)

تتضمن المنصة واجهات برمجية شاملة ومعيارية (RESTful APIs) تغطي كافة متطلبات إدارة الموردين، الامتثال، الاشتراكات، والتحقق.

- **التوثيق التفاعلي المباشر (Interactive API Docs)**:  
  تأتي المنصة مجهزة بصفحة توثيق تفاعلية مدعومة بـ **OpenAPI / Swagger** عبر حزمة **Dedoc Scramble**، تتيح للمطورين استعراض كافة الـ Endpoints وتجربة الطلبات مباشرة عبر الرابط:
  ```text
  http://localhost:8000/docs/api
  ```
- **المصادقة والأمان**:  
  تعتمد واجهات الـ API على رموز الوصول الرقمية الموثقة (**Laravel Sanctum Bearer Tokens**) مع قيود التحقق الصارم ومعدل الطلبات المسموح (Rate Limiting).

## 🚀 دليل التشغيل السريع (Quickstart Guide)

### 1. المتطلبات الأساسية
- **PHP**: إصدار 8.2 أو أحدث.
- **Composer**: مدير حزم PHP.
- **قاعدة البيانات**: MySQL 8.0+ أو PostgreSQL 14+.

### 2. التثبيت والتهيئة
```bash
# استنساخ المشروع
git clone https://github.com/Mohammed-Alssadi/VendorProof-saas-admin.git
cd VendorProof-saas-admin

# تثبيت الحزم البرمجية
composer install

# إنشاء ملف البيئة وتوليد مفتاح التشفير
cp .env.example .env
php artisan key:generate
```

### 3. إعداد قاعدة البيانات والبيانات الأولية
قم بضبط بيانات الاتصال بقاعدة البيانات في ملف `.env`، ثم قم بتشغيل الترحيلات والبذور:
```bash
php artisan migrate --seed
```

### 4. تشغيل خادم التطوير
```bash
php artisan storage:link
php artisan serve
```

- **لوحة تحكم الإدارة**: `http://localhost:8000/login`
- **حساب المشرف الافتراضي**: `admin@vendorproof.sa` | **كلمة المرور**: `Password123!`
- **التوثيق التفاعلي للـ API**: `http://localhost:8000/docs/api`
